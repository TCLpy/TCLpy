TCLpy 🚀

A Lightweight, Zero-Dependency Native Tcl 8.6 & Python Bridge

📖 View Tutorial GitHub Repository PyPI Package

Overview

tclpy is a high-performance, open-source Tcl-to-Python bridge and execution engine powered by Python's native tkinter.Tcl() interpreter (Tcl 8.6.15). By leveraging the robust C-extension core of Tcl 8.6 directly, it provides full-spec Tcl execution alongside seamless Python interoperability via clean bridge commands like py_exec, py_eval, and py_import.

Installation

Install the package directly from PyPI:

pip install ASTpytcl

Or install locally in editable mode for development:

git clone https://github.com/TCLpy/TCLpy.git
cd TCLpy
pip install -e .

Embedding in Python

tclpy provides a clean, top-level Python API allowing you to evaluate Tcl strings and source script files while sharing state via environment dictionaries:

import tclpy

# Shared state environment dictionary
env = {"a": 15, "b": 25}

# Evaluate Tcl expressions directly
tclpy.eval('set product [expr {$a * $b}]', env)
print(env["product"])  # Output: 375

# Source and execute .tcl script files
tclpy.source("script.tcl", env)

Key Features

  • Native Tcl 8.6.15 Engine: Built on Python's robust tkinter.Tcl interpreter for complete Tcl language standards compliance.
  • Python Embedding API: Seamlessly integrate Tcl logic into Python apps using tclpy.eval() and tclpy.source().
  • Direct Python Interop: Import modules and run inline code via py_import and py_exec with automated indentation handling.
  • Interactive REPL Shell: Features built-in readline history navigation and brace/bracket balancing for multi-line block entry.
  • Zero-Dependency & Cross-Platform: Designed for high performance across Windows, Termux, and Pydroid 3.

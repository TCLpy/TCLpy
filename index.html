TCLpy 🚀

A Lightweight, Zero-Dependency Tcl-to-Python Compiler & FFI Bridge

View on GitHub Documentation

Overview

tclpy is a high-performance, open-source Tcl-to-Python bridge and execution engine. Instead of running a string-based interpreter, it compiles Tcl source code directly into native CPython AST nodes, delivering seamless Python interoperability while preserving Tcl's core command semantics.

Quickstart

git clone https://github.com/TCLpy/TCLpy.git
cd tclpy
pip install -e .

# Run interactive REPL or scripts
tclpy

Key Features

  • AST-Based Compilation: Compiles Tcl control flow directly into CPython AST nodes for native execution speed.
  • Direct Python Interop: Import any Python module via py::import using Tcl double-colon notation.
  • Hybrid Execution: Delegate complex object mutation or heavy loops to Python via `py_exec`.
  • Zero-Dependency: Minimalist architecture designed for high performance and clarity.
